## 1. What this supersedes

- **Compute frontier.** The old frontier's "6.6×" (`paper/WINDOWED_RESULTS.md` §3: W2-only per-flow marginal 0.0602 s ÷ W=25 campaign marginal 0.009064 s) is **superseded**: the per-flow figure excluded Rips construction. On the like-for-like full-path latency harness (n=30), per-flow costs 3.5762 s per decision and W=25 costs 0.007486 s per decision, a **478×** per-decision speedup (one decision covers 25 flows). Per-flow AUC stays the Phase-4 10-seed probe value 0.8930.
- **Window counts.** `paper/WINDOWED_RESULTS.md` quoted window counts pooled over 10 ordered repeats (e.g. W=25: 7330 windows, 1430 Blackhole-majority); the repeats share window membership, so the unique population is 733 windows / 143 Blackhole-majority (§4).
- **FPR claim now measured.** At the val-Normal Q95 threshold on the high-precision (δ≤0.01) full-test campaign, canonical z-norm all-three scoring gives test FPR 0.0555 and TPR 0.5703 (val exceedance 0.0502; §3).

**Caption-level caveats.**

- *Wormhole at W=50 is effectively a tie:* Network 0.8140 [0.8009, 0.8269] vs Physical 0.8096 [0.7926, 0.8270] (difference 0.0044); the CIs overlap, so the Network dominance marked in the attribution figure should not be read as a resolved attribution.
- *Attribution figure blocks are not like-for-like:* the per-flow block is a single full-test estimate (`exact/exact_per_attack_auc.csv`), whereas each windowed block is a 10-run mean (`windowed/windowed_attribution.csv`).
- *Thin contamination bins:* the smallest non-empty ordered-arm bin is n=1 unique windows (W=100, bin 0, detection rate 0.0000); 1 bin(s) are empty (W=200 bin 0). Rates in thin bins are low-power.
