## 1. What this supersedes

- **Compute frontier.** The old frontier's "6.6×" (`paper/WINDOWED_RESULTS.md` §3: W2-only per-flow marginal 0.0602 s ÷ W=25 campaign marginal 0.009064 s) is **superseded**: the per-flow figure excluded Rips construction. On the like-for-like full-path latency harness (n=30), per-flow costs 3.5762 s per decision and W=25 costs 0.007486 s per decision, a **478×** per-decision speedup (one decision covers 25 flows). Per-flow AUC stays the Phase-4 10-seed probe value 0.8930.
- **Window counts.** `paper/WINDOWED_RESULTS.md` quoted window counts pooled over 10 ordered repeats (e.g. W=25: 7330 windows, 1430 Blackhole-majority); the repeats share window membership, so the unique population is 733 windows / 143 Blackhole-majority (§4).
- **FPR claim now measured.** At the val-Normal Q95 threshold on the high-precision (δ≤0.01) full-test campaign, canonical z-norm all-three scoring gives test FPR 0.0555 and TPR 0.5703 (val exceedance 0.0502; §3).

**Caption-level caveats.**

- *Unresolved attributions:* in 9 attribution cells (of 20 attack × block cells) the dominant manifold's CI low is at or below the runner-up's CI high (the CIs overlap; a conservative rule, not a paired test), so the dominance marked in the attribution figure should not be read as a resolved attribution there:

  - Wormhole W=25: dominant Network 0.8230 [0.7899, 0.8549] vs runner-up Physical 0.7707 [0.7264, 0.8085] (difference 0.0523)

  - Wormhole W=50: dominant Network 0.8140 [0.7721, 0.8529] vs runner-up Physical 0.8096 [0.7504, 0.8623] (difference 0.0044)
  - Flooding W=100: dominant C2 0.7102 [0.6444, 0.7708] vs runner-up Network 0.6775 [0.5735, 0.7774] (difference 0.0328)
  - Wormhole W=100: dominant Physical 0.8704 [0.8038, 0.9293] vs runner-up Network 0.7968 [0.7338, 0.8580] (difference 0.0735)
  - Flooding W=200: dominant Network 0.7467 [0.6196, 0.8712] vs runner-up C2 0.6965 [0.5974, 0.7965] (difference 0.0502)
  - Blackhole W=200: dominant Physical 0.5585 [0.4057, 0.7171] vs runner-up C2 0.3516 [0.2529, 0.4525] (difference 0.2069)
  - Wormhole W=200: dominant Physical 0.8655 [0.7631, 0.9496] vs runner-up Network 0.7865 [0.7036, 0.8644] (difference 0.0789)
- *Windowed intervals:* ordered-arm CIs resample each window once per replicate across all repeats and treat windows as independent. Neighbouring windows are correlated, so they are optimistic: the frontier table, figures and snippet give the block-10 bootstrap interval beside each. These cover the all-three z-norm detection AUC only; attribution and contamination CIs have no block version. `paper/WINDOWED_RESULTS.md` §2 has every block length; §6 lists dominant cells whose CI reaches AUC 0.5.
- *Per-flow headline interval:* 0.9082 treats flows as independent ([0.9033, 0.9129] by this bootstrap), but consecutive same-class flows are correlated (rank lag-1 0.263). Block-bootstrap intervals (block 10: [0.9010, 0.9151], block 50: [0.8955, 0.9191], block 100: [0.8923, 0.9225], block 250: [0.8852, 0.9299], block 500: [0.8825, 0.9340]) are wider; `paper/EXACT_RESULTS.md` §2.2.
- *Windowed cost scope:* the latency harness's windowed `total_s` is Rips + W2 (per-dimension diagram slicing inside the timed W2 call; no top-K truncation). It has no scaler stage: window flows are read pre-scaled, so scaling them is untimed (order of magnitude: the per-flow scaler stage totals 2.51 ms across the three manifolds in the latency summary). It also excludes the one-time `baseline_setup_s` (49.45–78.09 s across W). The W=25 478× speedup is therefore an upper-end figure.
- *AUC units differ between arms:* per-flow AUC is flow-level, windowed AUC is window-level (majority label). The frontier and detection-vs-W figures put both on one axis, so cross-arm AUC comparisons are indicative, not like-for-like (see "Unit caveat (M2)" in `paper/WINDOWED_RESULTS.md`).
- *Two different thresholds:* the contamination figure's detection rate uses the empirical near-normal Q95 threshold computed per (W, arm) in `windowed/contamination_curve.csv` from windows with attack_frac ≤ 0.05, not the val-Normal Q95 threshold of §3. That reference population is small at large W (unique near-normal windows W=25: 43, W=50: 16, W=100: 9, W=200: 5; §4).
- *Attribution figure blocks are not like-for-like:* the per-flow block is a single full-test estimate (`exact/exact_per_attack_auc.csv`), whereas each windowed block is a 10-run mean (`windowed/windowed_attribution.csv`).
- *Thin contamination bins:* the smallest non-empty ordered-arm bin is n=1 unique windows (W=100, bin 0, detection rate 0.0000); 1 bin(s) are empty (W=200 bin 0). Rates in thin bins are low-power.
