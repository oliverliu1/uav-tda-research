## Methodology note (deviation from PROJECT_BRIEF.md SS10 item 2)

PROJECT_BRIEF.md specifies using validation-set Normal-Traffic distances for Z-normalization. The probe only computes W_2 on the test split, so this diagnostic substitutes the 200 test Normal-Traffic flows present in `probe_distances.csv` as the empirical Normal reference. For comparison, the val split contains 3926 Normal-Traffic flows. Re-running with a true val reference requires extending the probe to compute val W_2 inline (would add ~5-10s of compute and roughly 60 lines of code; not done here to stay within the script-shape constraints stated in the brief). The expected effect of using test Normal-Traffic for normalization is a mild upward bias on the Normal-vs-Attack AUC because the Normal class is centered at zero post-normalization on the same data evaluated; the verdict thresholds in the brief still distinguish artifact from substantive findings comfortably given this bias direction.
