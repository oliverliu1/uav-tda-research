# SciTech 2027 full manuscript (in progress)

Working copy of the full manuscript. The extended abstract as submitted is in
`../SciTech2027_IntelligentSystems_Liu/` and is not edited.

- **Plan:** `docs/superpowers/plans/2026-11-23-plan9-manuscript-rewrite.md`.
- **Build:** `make manuscript` from the repo root (output in `build/`, not tracked). It needs
  the repo around it: numbers, figures and snippets are read by relative path.
- **Numbers:** running text uses macros such as `\AucFullAllThree{}` from
  `results/tables/rebuild/paper_snippets/manuscript_numbers.tex`, generated by
  `uav-tda manuscript-numbers` from the committed CSVs. To cite a new number, add it to
  `NUMBERS` in `uav_tda/manuscript_numbers.py`; do not type digits into the text.
- **Figures:** the generated PDFs in `results/figures/manuscript/` (on `\graphicspath`).
- **Template:** AIAA `new-aiaa.cls` / `new-aiaa.bst` as supplied; no page limit.
